# Kevin "Tyler" Cox

I am a software engineer in Charleston, South Carolina, with more than 11 years of experience building production applications and the systems around them.

Professionally, my work has centered on Angular and TypeScript applications for logistics operations, backed by Java/Spring Boot and C#/.NET services. I have also worked deeply in delivery automation, identity, observability, Kubernetes, GCP, Kafka-based data integration, and the practical operating concerns that determine whether software is actually dependable.

Outside of work, I use game and platform projects to explore problems that demand more than straightforward application code. My current projects include a persistent multiplayer roleplay platform and a server-side modding framework created by reverse-engineering a proprietary Windows dedicated server. Those projects span TypeScript, Angular, Firebase, .NET, Rust, C++, Lua, native hooks, telemetry, desktop tooling, packaging, and live validation.

The common thread is system ownership. I like finding the behavior hidden behind a complicated interface, making it observable, and giving users or operators a safer way to control it.

I am currently looking for remote U.S. Software Engineer III, Senior Software Engineer, or equivalent roles in full-stack engineering, frontend platform, developer infrastructure, or observability.
